## 🚀 Selected projects

### 01 / SmartFest
**From event discovery to digital check-in.**

An event management and ticketing platform for college fests, student clubs, and academic events.

- Supports participant bookings, organiser workflows, and administrative approvals.
- Uses database row locking and temporary reservations to manage seat allocation.
- Includes waitlist promotion, Razorpay integration, and QR-based digital passes.
- Connects a React interface with a Python API and PostgreSQL database.

**Built with:** React · Tailwind CSS · FastAPI · PostgreSQL · SQLAlchemy  
**Deployment:** Vercel frontend · Render backend

[**Explore SmartFest →**](https://smart-fest-navy.vercel.app/)

> **Let's talk engineering:** What happens when two people try to book the last seat? How should an expired reservation affect the waitlist?

### 02 / Motherland Tourism
**Helping travellers discover India through local guides.**

A full-stack tourism project focused on guide discovery and booking workflows.

- Organises experiences around travellers, guides, and administrators.
- Includes guide profiles, booking management, reviews, and dashboards.
- Combines a vanilla JavaScript frontend with a Flask API and relational data models.

**Built with:** Python · Flask · HTML · CSS · JavaScript · PostgreSQL  
**Project stage:** Academic project; payment flow uses a mock system.

> **Let's talk product:** How should traveller and guide workflows differ while sharing the same booking data?

### 03 / Parlour Pro Management
**Bringing everyday salon operations into one application.**

A management application built to organise the day-to-day work of a beauty parlour.

- Manages customers, services, appointments, and staff.
- Integrates Firebase for authentication and cloud data management.
- Provides a user-friendly interface for routine parlour operations.

**Built with:** Flutter · Dart · Firebase

> **Let's talk workflows:** How should customer records, appointments, services, and staff fit together in a useful management application?

### 04 / AURA — Project Concept
**Making resource usage visible to support greener decisions.**

A concept for bringing computer monitoring, cost analytics, and environmental insights into one platform, helping organisations understand how they use computing resources.

**Focus:** System visibility · Operating costs · Sustainability  
**Project stage:** Concept and presentation; exploring the product and business model.
